## 每天完成的最低标准

如果当天很忙，不要因为做不满 20 分钟直接放弃。

最低版 8 分钟：

1. 2 min 看当天核心规律。
2. 2 min 听 3 个例子。
3. 2 min 跟读 3 遍。
4. 2 min 自己说 2 句陌生句。

**保持连续性 > 某一天练得特别久。**
