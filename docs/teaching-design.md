# oralEnglish 教学设计

这套课程不是“每天看一个发音视频”，而是把成熟的发音教学框架压缩成每天 20 分钟可执行训练。

## 一、课程目标

6 周后，不追求“像母语者”，而追求 4 个可检验能力：

1. **听得出**：能在真实美式语流里发现重音、弱读、linking、T 变化等现象。
2. **说得出**：在控制练习和短句中稳定复现当天目标。
3. **能迁移**：遇到没练过的句子，可以先预测自然语流，再验证。
4. **能自纠**：会用录音、YouGlish、真人语料定位自己的差异。

---

## 二、核心教学框架：5 阶段 Pronunciation Cycle

课程参考 Celce-Murcia / Brinton / Goodwin 的 Communicative Framework for Teaching Pronunciation，并根据“每天只有 20 分钟”的约束做了压缩。

### Stage 1 — Awareness / Description（2–3 min）

先回答两个问题：

- 今天到底学什么？
- 为什么自然英语会这样说？

成人学习者不只需要模仿，也需要建立规则意识。每天只讲 **1 个核心规律**，避免理论过载。

### Stage 2 — Listening Discrimination（3–4 min）

先听出来，再要求自己说出来。

典型任务：

- A / B 哪个更自然？
- 这句里 `to` 是强读还是弱读？
- 你听到完整的 /t/ 了吗？
- 哪两个词之间没有明显断点？

### Stage 3 — Controlled Production（4–5 min）

在注意力主要放在发音形式时练习。

典型任务：

- 3–5 个短语慢速 → 正常速度。
- 影子跟读 3 遍。
- 用 `/` 标 thought groups，用 `_` 标 linking，用 `●` 标 prominence。

### Stage 4 — Guided Production（4–5 min）

开始从“照抄”过渡到“自己生成”。

典型任务：

- 给一个句型，自己替换 3 个内容词。
- 老师给 1 个例子，自己造 3 个没见过的句子。
- 先预测连接和弱读，再读出来。

### Stage 5 — Communicative Transfer（3–4 min）

当天最后必须脱离教材说一点真实内容。

典型任务：

- 用今天的结构回答一个真实问题 20–30 秒。
- 复述今天发生的一件事。
- 用目标现象说 3 句自己的话。

最后用 YouGlish / 原音 / 自己录音做一次快速校准。

# 三、每天 20 分钟固定模板

| 时间 | 阶段 | 做什么 |
|---|---|---|
| 0–3 min | Awareness | 只学 1 个规则 + 2 个例子 |
| 3–7 min | Listening | 听辨 3–5 个真实样本 |
| 7–12 min | Controlled | 跟读 / shadowing / 节奏模仿 |
| 12–17 min | Guided | 自己生成 3–5 个陌生句 |
| 17–20 min | Transfer | 20–30 秒自由输出 + 录音/验证 |

> 每天必须走到最后一步。只看课程、不输出，不算完成。

# 四、为什么先学“超音段”再大量学连读

课程顺序不是随便排的。

真实 connected speech 很大程度上受 **stress / prominence / rhythm** 影响：非重读成分更容易缩短、弱化、变成 schwa，甚至发生删除或声音变化。

因此课程先建立：

`Thought Groups → Prominence → Rhythm → Schwa / Weak Forms`

再进入：

`C-V Linking → C-C Linking → V-V Linking → Reduction → T system → Assimilation / Elision`

最后用真实语料整合。

这比一开始背“100 个连读短语”更容易迁移。

# 六、训练标记法

以后所有讲义统一用：

- `/` = thought-group boundary
- `●WORD` = prominence / 主要重音
- `_` = 词边界 linking
- `(ə)` = 明显弱化 / schwa 提示
- `[T→ɾ]` = Flap T
- `[T stop]` = Stop T
- `[Ø]` = 可能发生删除
- `[→]` = assimilation / modification

标记只是辅助，不追求把每句话标成语言学论文。

# 七、每周学习循环

## Day 1–5：新规律递进

每天只加一点新内容，并持续复用前几天规则。

## Day 6：真实语料整合

用 AEE / Rachel 真实对话，集中寻找本周现象。

## Day 7：复习 + 录音

不学新规则。

固定做：

1. 30 秒朗读。
2. 30 秒自由表达。
3. 与本周 Day 1 录音对比。
4. 只记录 **一个最明显问题**，下周优先纠正。

---

# 八、评价标准

不要用“像不像美国人”评价。

每周只检查四项：

| 能力 | 0 | 1 | 2 |
|---|---:|---:|---:|
| 听辨 | 几乎听不出 | 提醒后能听出 | 能主动发现 |
| 控制模仿 | 很不稳定 | 慢速能做到 | 正常速度能做到 |
| 陌生句迁移 | 只能背例句 | 部分能预测 | 大多能合理预测 |
| 自由输出 | 一说话就消失 | 偶尔能用 | 能较自然带入 |

每周满分 8 分。目标不是周周满分，而是让“迁移”和“自由输出”持续上升。
