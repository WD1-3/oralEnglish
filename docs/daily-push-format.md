# 每日推送格式

每日推送不是“提醒学习”，而是一节可以直接开始的 20 分钟微课。

固定结构：

## Day N｜今日主题

### 1. 今天只记一句话
用一句中文讲清核心规律。

### 2. 3 分钟讲义
只解释当天最必要的原理，不扩展无关术语。

### 3. 4 分钟听辨
给 3–5 个例子或真实语料观察任务。优先“先听再看答案”。

### 4. 5 分钟跟读
给 3–5 句，标出当天需要注意的位置。

### 5. 5 分钟迁移
给 2–4 个没在讲义里出现过的新句子，让学习者先自己判断，再验证。

### 6. 3 分钟自由输出
给一个和现实生活有关的问题，要求说 20–30 秒。

### 7. 今天完成标准
只给一个可判断的标准，例如：

> 看到陌生 C→V 边界时，能主动发现并慢速连续说出来。

### 8. 今日资料
最多 1–2 个主链接，不把每日推送变成资源列表。

---

## 推送原则

- 默认中文讲解 + 英文训练句。
- 20 分钟内可以完成。
- 每天只增加一个主要困难。
- 必须有“自己生成陌生句”环节。
- 必须有自由输出，避免永远停留在跟读。
- 新知识持续复用旧知识，例如学习 Flap T 时仍然检查 prominence / weak forms / linking。
- Day 7 / 14 / 21 / 28 / 35 / 42 不新增大量理论，以诊断和复盘为主。
- 不要求口音像母语者；优先 intelligibility、listening segmentation、rhythm 和自然连续度。
